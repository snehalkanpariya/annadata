# Annadata Backend

Backend API for Annadata — an agritech platform supporting P2P farming equipment rentals, agrochemical commerce, and AI diagnostics.

## Features Built So Far
- **Authentication**: JWT Access & Refresh Token architecture.
- **Role-based Access**: Custom schemas for Farmers and Admins.
- **Geospatial Readiness**: GeoJSON points indexed with MongoDB `2dsphere`.
